# Koebel Kids Games

Kid-friendly browser games, one self-contained game per folder, published on GitHub Pages.

## Play

- [Koebel Kids Games](https://koebelsundries.github.io/kids-games/)
- [Emberwing](https://koebelsundries.github.io/kids-games/emberwing/) — a dragon flying game with Little Rider, Normal, and Hard modes

## Add a game

Put a self-contained `index.html` in a new folder, link it from the root landing page, and push to `main`.
