# Koebel Kids Games

Kid-friendly browser games, one self-contained game per folder, published on GitHub Pages.

## Play

- [Koebel Kids Games](https://koebelsundries.github.io/kids-games/)
- [Emberwing](https://koebelsundries.github.io/kids-games/emberwing/) — a pixel-art dragon flying game with Little Rider, Normal, and Hard modes. The old preview at `emberwing-pixel/` redirects here.
- [Goalburst](https://koebelsundries.github.io/kids-games/penalty-shootout/) — a 3D penalty-kick shootout: swipe to curve a shot, play keeper, or pass the phone for a sibling showdown
- [Sparkegg](https://koebelsundries.github.io/kids-games/paddle-duel/) — a two-player dragon-egg rally: sit at each end of the phone and keep the egg flying, with fair-play nest sizes for mixed ages

## Add a game

Put a self-contained `index.html` in a new folder, link it from the root landing page, and push to `main`.
